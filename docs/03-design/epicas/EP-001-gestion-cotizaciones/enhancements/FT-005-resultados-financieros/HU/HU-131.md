## 3. User Story
Como usuario,
Quiero ver el desglose de la prima calculada para cada ubicación de riesgo,
Para entender cómo se distribuye el costo total del seguro.

## 4. Functional Description
**Description:** Esta historia de usuario permite a un usuario visualizar el detalle de la prima calculada, desglosada por cada ubicación de riesgo asociada a una cotización. El sistema mostrará una lista o tabla de ubicaciones, cada una con su prima individual asignada y un indicador si la ubicación fue excluida del cálculo. El usuario también podrá seleccionar una ubicación para ver su prima en mayor detalle, asegurando que los valores numéricos estén correctamente formateados para su fácil comprensión.
**Flow:** HU-128 (Persistir Resultados del Cálculo de Prima) → HU-131 (Visualizar Desglose de Prima por Ubicación) → [Posiblemente una historia para Ajustar Ubicaciones o Cotización]

## 6. Acceptance Criteria (3-5 criteria)
### AC-001: Visualización del Desglose de Prima por Ubicación
**Description:** Valida que, una vez calculada la cotización, el usuario puede ver la prima asignada a cada ubicación calculable.

```gherkin
Scenario: El usuario visualiza el desglose de la prima por ubicación después de un cálculo exitoso
  Given una cotización ha sido calculada y sus resultados están disponibles
  When el usuario navega a la sección de resultados de la cotización
  Then se muestra una lista o tabla de ubicaciones con la prima asignada a cada ubicación calculable
  And cada ubicación debe indicar si fue excluida del cálculo
```

### AC-002: Visualización Detallada de Prima por Ubicación Específica
**Description:** Valida que el usuario puede acceder a una vista detallada de la prima individual de una ubicación seleccionada.

```gherkin
Scenario: El usuario selecciona una ubicación para ver su detalle de prima
  Given el desglose de la prima por ubicación se está mostrando
  When el usuario selecciona una ubicación específica de la lista
  Then se muestra una vista detallada de la prima individual para esa ubicación
```

### AC-003: Formato Correcto de Valores de Prima
**Description:** Valida que todos los valores numéricos de la prima se muestran con el formato monetario adecuado.

```gherkin
Scenario: Los valores de la prima se muestran con el formato correcto
  Given el desglose de la prima por ubicación está siendo visualizado
  When se muestran los valores de la prima por ubicación (tanto en la lista general como en el detalle)
  Then los valores numéricos de la prima están formateados correctamente como moneda (ej. $1,234.56)
```

## 13. Edge Cases and Exceptions
### Case 1: No hay ubicaciones asociadas a la cotización
```gherkin
Scenario: La cotización no tiene ubicaciones asociadas
  Given una cotización ha sido calculada pero no tiene ubicaciones de riesgo registradas
  When el usuario navega a la sección de resultados de la cotización
  Then la sección de desglose de prima por ubicación muestra un mensaje indicando que no hay ubicaciones
  And no se muestra ninguna lista o tabla de ubicaciones
```

### Case 2: Todas las ubicaciones están excluidas del cálculo
```gherkin
Scenario: Todas las ubicaciones están excluidas del cálculo de prima
  Given una cotización ha sido calculada y todas sus ubicaciones de riesgo están marcadas como excluidas
  When el usuario navega a la sección de resultados de la cotización
  Then se muestra la lista o tabla de ubicaciones
  And cada ubicación tiene el indicador de 'excluida' visible
  And la prima asignada a cada ubicación excluida es 0.00 o se indica como 'N/A'
```

### Case 3: Error al cargar los datos de la prima
```gherkin
Scenario: Falla la carga de datos de la prima por ubicación
  Given una cotización ha sido calculada
  And el servicio de backend para obtener el desglose de prima falla o devuelve un error
  When el usuario navega a la sección de resultados de la cotización
  Then se muestra un mensaje de error al usuario (ej. "No se pudieron cargar los datos de prima. Intente más tarde.")
```

## 16. Technical Notes and Risks
**Risks:**
1.  **Riesgo: Consistencia de datos.**
    *   Descripción: Los datos de prima por ubicación obtenidos de la persistencia podrían no coincidir con el cálculo original o estar incompletos.
    *   Impacto: Información incorrecta para el usuario, afectando la confianza y la toma de decisiones.
    *   Probabilidad: Media
    *   Mitigación: Implementar validaciones de integridad de datos al persistir (HU-128) y al recuperar. Asegurar una única fuente de verdad para los resultados del cálculo.
2.  **Riesgo: Rendimiento de la UI.**
    *   Descripción: Si una cotización tiene un número muy elevado de ubicaciones, la carga y renderización de la tabla podría ser lenta.
    *   Impacto: Mala experiencia de usuario, frustración.
    *   Probabilidad: Baja a Media (dependiendo del límite de ubicaciones)
    *   Mitigación: Implementar paginación o virtualización de listas en el frontend si el número de ubicaciones excede un umbral. Optimizar la consulta de backend.

**Technical Debt:** N/A (Se llenará por el equipo operativo si se identifican atajos o soluciones temporales durante la implementación).

## 17. Criticality
**Criticality Level:** Alta
**Justification:** Esta historia es fundamental para el valor de negocio principal de la funcionalidad de cotización. Sin ella, el usuario no puede comprender el desglose de los costos, lo cual es crucial para la transparencia y la toma de decisiones.
**Feature Impact:** La no implementación o el fallo de esta historia haría que la funcionalidad de "Cálculo de Prima" fuera incompleta y de bajo valor para el usuario final, ya que solo vería un total sin detalles.
**Critical Dependencies:** Depende críticamente de que HU-128 persista los datos de forma correcta y completa.
**Recommended Priority:** Sprint actual o siguiente.

## 18. Identified Assumptions
1.  **Formato de Moneda**
    *   Description: Se asume que el sistema tiene una configuración global o por usuario para el formato de moneda (símbolo, separador de miles/decimales) que se aplicará automáticamente a los valores de prima.
    *   Impact if false: Los valores de prima podrían mostrarse sin formato o con un formato incorrecto, dificultando la lectura y comprensión.
    *   Requires validation from: Equipo de UX/Diseño, Equipo de Backend (para configuración global).
2.  **Disponibilidad de Datos de Ubicación**
    *   Description: Se asume que los nombres y la información básica de las ubicaciones están disponibles y son accesibles junto con los datos de prima.
    *   Impact if false: La tabla o lista de desglose no podría mostrar información significativa sobre cada ubicación.
    *   Requires validation from: Equipo de Backend, Dueño del Producto.
