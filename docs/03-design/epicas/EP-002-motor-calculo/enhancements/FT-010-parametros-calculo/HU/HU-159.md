## 2. Enabled Capability
**CAP-001:** Obtención de Tarifas de Incendio
**Business Value:** Permite al motor de cálculo de primas obtener las tasas base necesarias para calcular las primas de incendio de manera precisa y consistente, asegurando la funcionalidad central del sistema.
**Requires:** HU-092 (Configurar Mock Server Base, FT-020)
**Enables:** CAP-002 - Cálculo de Primas de Incendio (CAP-XXX - "Cálculo de primas" sería una capacidad posterior que consume estas tarifas)
**Orchestrates:** Plataforma-core-ohs

## 3. User Story
Como sistema,
Quiero consumir o simular la consulta de `tarifas_incendio` del servicio `Plataforma-core-ohs`,
Para obtener las tasas base necesarias para el cálculo de primas.

## 4. Functional Description
**Description:** El sistema debe ser capaz de consultar las tarifas de incendio desde el servicio `Plataforma-core-ohs`. En caso de que el servicio real no esté disponible o para propósitos de desarrollo/pruebas, el sistema debe poder simular esta consulta utilizando un mock server. Una vez obtenidas, las tarifas deben ser mapeadas al formato interno y estar disponibles para el módulo de cálculo de primas. Se debe implementar un manejo de excepciones robusto para cuando el servicio de tarifas no esté disponible.
**Flow:** [Configuración Mock Server Base (HU-092)] → [HU-159 - Consumir Tarifas de Incendio] → [Cálculo de Primas (US-XXX)]

## 11. Architecture and Technical Dependencies
- **Plataforma-core-ohs**: Servicio externo para obtener `tarifas_incendio`. Propósito: Fuente de datos de tasas base. Timeout: 5 segundos. Retries: 3 intentos con backoff exponencial.
- **Backend (Adaptador)**: Componente encargado de la lógica de conexión, consumo y mapeo de datos de `Plataforma-core-ohs`.
- **Repositorio de Parámetros**: Posiblemente utilizado para almacenar configuraciones de la integración o incluso para cachear las tarifas de incendio si se considera necesario.
- **Mock Server Base (HU-092, FT-020)**: Entorno de simulación para pruebas y desarrollo, debe emular el comportamiento y contratos de `Plataforma-core-ohs`.
- **Circuit Breaker**: Implementar un patrón Circuit Breaker para la llamada a `Plataforma-core-ohs` para manejar fallos de forma resiliente.

## 16. Technical Notes and Risks
**Risks:**
1.  **Desincronización del Mock:**
    -   Descripción: El mock server utilizado para simular `Plataforma-core-ohs` podría no reflejar fielmente el contrato o comportamiento de la API real, llevando a problemas de integración en producción.
    -   Impacto: Errores inesperados en producción, retrabajos, retrasos en la entrega.
    -   Probabilidad: Media.
    -   Mitigación: Mantener el mock server actualizado con el contrato de la API real. Realizar pruebas de integración exhaustivas con el servicio real en entornos de staging.
2.  **Cambios en el Contrato de `Plataforma-core-ohs`:**
    -   Descripción: Cambios inesperados en la API de `Plataforma-core-ohs` (ej. adición/eliminación de campos, cambio de tipos de datos) podrían romper la integración.
    -   Impacto: Fallo en la obtención de tarifas, impacto directo en el cálculo de primas.
    -   Probabilidad: Baja (se asume estabilidad de APIs internas), pero de alto impacto.
    -   Mitigación: Establecer comunicación con el equipo de `Plataforma-core-ohs` para ser notificados de cambios. Implementar validación de esquema en la respuesta. Usar un contrato de API (ej. OpenAPI/Swagger) como fuente de verdad.

## 17. Criticality
**Criticality Level:** Alta
**Justification:** Esta historia es crítica porque proporciona las tasas base (`tarifas_incendio`) que son fundamentales para la funcionalidad principal del motor de cálculo de primas. Sin estas tarifas, el sistema no puede realizar su función esencial de calcular primas de incendio.
**Feature Impact:** La no implementación o el fallo de esta historia detendría completamente la capacidad del sistema para calcular primas de incendio, haciendo que la funcionalidad de "Gestión de Tarifas" y "Cálculo de Primas" sea inoperable.
**Critical Dependencies:** Todas las historias relacionadas con el cálculo de primas de incendio dependen directamente de la disponibilidad y precisión de estas tarifas.
**Recommended Priority:** Sprint actual o ASAP, debido a su naturaleza fundamental.
