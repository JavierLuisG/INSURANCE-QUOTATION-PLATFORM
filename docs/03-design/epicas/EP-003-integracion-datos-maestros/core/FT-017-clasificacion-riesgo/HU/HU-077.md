## 1. Identificación General / General Identification
**Feature:** Configuración de Coberturas de Cotización
**Capability:** CAP-001 - Recuperación de Catálogos Externos
**Actor:** Sistema (en nombre del usuario que configura coberturas)
**Bounded Context:** Cotización / Suscripción
**Story Points:** 3

## 2. Enabled Capability
**CAP-001:** Recuperación de Catálogos Externos
**Business Value:** Garantizar que las opciones de clasificación de riesgo en la definición de coberturas sean actuales y válidas, lo que impacta directamente en la precisión de las primas y condiciones de suscripción.
**Requires:** CAP-### (Conectividad Básica - Implícito por HU-068)
**Enables:** CAP-### (Definición de Coberturas, Cálculo de Primas)
**Orchestrates:** `Plataforma-core-ohs` (o su mock)

## 3. User Story
Como sistema,
Quiero recuperar el catálogo de clasificación de riesgo desde el servicio `Plataforma-core-ohs` (o su mock),
Para ofrecer opciones actualizadas en la definición de coberturas de la cotización.

## 4. Functional Description
**Description:** Esta historia de usuario describe la funcionalidad por la cual el sistema obtiene la lista de clasificaciones de riesgo disponibles desde un servicio externo (`Plataforma-core-ohs` o su mock). El propósito es asegurar que los usuarios que configuran coberturas en una cotización tengan acceso a la información más reciente y precisa sobre los tipos de riesgo, lo cual es fundamental para el cálculo de primas y la aplicación de condiciones de suscripción. En caso de éxito, el catálogo se presenta al usuario para su selección; en caso de fallo, se registra el error y se notifica al usuario.
**Flow:** HU-068 (Conectividad básica) → **HU-077 (Recuperar Catálogo de Clasificación de Riesgo)** → Definición de Coberturas (selección de clasificación)

## 16. Technical Notes and Risks
**Risks:**
1.  **Disponibilidad del Servicio Externo:**
    -   Descripción: El servicio `Plataforma-core-ohs` podría no estar disponible o tener alta latencia.
    -   Impacto: No se pueden obtener clasificaciones de riesgo actualizadas, afectando la definición de coberturas y el cálculo de primas.
    -   Probabilidad: Media.
    -   Mitigación: Implementar reintentos con backoff, Circuit Breaker, caché del catálogo (si la frescura no es crítica), monitorización y alertas.
2.  **Cambios en la API Externa:**
    -   Descripción: El formato de respuesta o endpoints del servicio `Plataforma-core-ohs` podrían cambiar sin previo aviso.
    -   Impacto: Fallos en el mapeo de datos y en la recuperación del catálogo.
    -   Probabilidad: Baja (si hay buena comunicación entre equipos), Media (si no la hay).
    -   Mitigación: Acuerdos de contrato con el equipo de `Plataforma-core-ohs`, pruebas de contrato (Consumer-Driven Contracts), monitorización de errores de mapeo.

**Technical Debt:** [To be filled by operating team per scope and MVP]

## 17. Criticality
**Criticality Level:** Medium
**Justification:** Aunque la no disponibilidad del catálogo no impide completamente la cotización (se podría usar un valor por defecto o manual), limita la capacidad de ofrecer opciones actualizadas y precisas, lo que es clave para la calidad de la cotización y la suscripción.
**Feature Impact:** La no implementación o fallo afectaría la precisión y la automatización de la definición de coberturas, requiriendo intervención manual o utilizando datos obsoletos/incorrectos.
**Critical Dependencies:** La funcionalidad de "Definición de Coberturas" y "Cálculo de Primas" dependen de este catálogo para operar de manera óptima.
**Recommended Priority:** Sprint actual / Próximo sprint (dada la prioridad 'Media' y la dependencia de funcionalidades clave).

## 18. Identified Assumptions
1.  **Formato de Respuesta del Servicio Externo**
    -   Description: Se asume que el servicio `Plataforma-core-ohs` devolverá el catálogo en un formato JSON o XML predecible y consistente, con los campos `id`, `nombre` y `descripción` para cada clasificación de riesgo.
    -   Impact if false: El mapeo de datos fallará, impidiendo la visualización del catálogo.

    -   Impact if false: La aplicación podría ralentizarse o consumir mucha memoria.
    -   Requires validation from: Equipo de `Plataforma-core-ohs` (sobre el tamaño actual y esperado del catálogo).
