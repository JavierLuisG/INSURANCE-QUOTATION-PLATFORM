## 1. Identificación General
**Feature:** Gestión de Tarifas de Catástrofe (CAT)
**Capability:** CAP-001 - Consumir Tarifas de Catástrofe
**Actor:** Sistema
**Bounded Context:** Motor de Cálculo / Configuración de Parámetros
**Story Points:** 3

## 2. Enabled Capability
**CAP-001:** Consumir Tarifas de Catástrofe
**Business Value:** Aplicar los factores de catástrofe según la zona de riesgo, asegurando cálculos de pólizas precisos y una evaluación de riesgo completa.
**Requires:** HU-092 (Configurar Mock Server Base, FT-020)
**Enables:** Cálculo de primas/pólizas con factores de catástrofe aplicados.
**Orchestrates:** Servicio externo `Plataforma-core-ohs`

## 3. User Story
Como sistema,
Quiero consumir o simular la consulta de `tarifas_cat` del servicio `Plataforma-core-ohs`,
Para aplicar los factores de catástrofe según la zona de riesgo.

## 4. Functional Description
**Description:** Esta historia de usuario describe la funcionalidad por la cual el sistema obtendrá las tarifas de catástrofe (CAT) necesarias para el motor de cálculo. La información se consultará desde el servicio externo `Plataforma-core-ohs`. En entornos de desarrollo o pruebas, o en caso de indisponibilidad del servicio real, se utilizará un mock server previamente configurado. Una vez recibidas las tarifas, el sistema deberá procesarlas, mapearlas a su formato interno y dejarlas disponibles para que el motor de cálculo pueda identificar y aplicar el factor de catástrofe correcto según la zona de riesgo determinada.
**Flow:** HU-092 (Configurar Mock Server Base) → **HU-160 (Consumir Tarifas de Catástrofe)** → [Cálculo de pólizas/primas con factores CAT aplicados]

**BR-001:** Mapeo de Tarifas CAT
- Description: Las tarifas de catástrofe recibidas del servicio `Plataforma-core-ohs` (o del mock) deben ser transformadas a la estructura de datos interna que utiliza el motor de cálculo.
- Trigger: Después de una consulta exitosa y recepción de `tarifas_cat`.
- Logic: Implementar un adaptador o transformador que convierta el formato de origen al formato de destino interno.
- Implementation: Backend (Adaptador para `Plataforma-core-ohs`).
- Exception: Si el formato de origen es inesperado o incompleto, se debe registrar un error y las tarifas no deben ser consideradas válidas.

**BR-002:** Selección de Factor CAT por Zona
- Description: El sistema debe ser capaz de identificar y seleccionar el factor de catástrofe específico que corresponde a una `zona_riesgo` dada, de entre las tarifas disponibles.
- Trigger: Cuando el motor de cálculo solicita el factor CAT para una `zona_riesgo`.
- Logic: Buscar en el conjunto de `tarifas_cat` mapeadas el `factor_catastrofe` asociado a la `zona_riesgo` proporcionada.
- Implementation: Repositorio de Parámetros / Lógica del Motor de Cálculo.
- Exception: Si no se encuentra un factor para la zona, se debe registrar una advertencia y/o aplicar un factor por defecto (Pendiente de definir si aplica un default o se lanza un error).

## 16. Technical Notes and Risks
**Risks:**
1.  **Nombre:** Disponibilidad y Estabilidad de `Plataforma-core-ohs`.
    -   **Descripción:** El servicio externo `Plataforma-core-ohs` podría presentar interrupciones, alta latencia o devolver datos inconsistentes, afectando la obtención de las tarifas.
    -   **Impacto:** Cálculos de primas incorrectos o incompletos, retrasos en la generación de pólizas, impacto en la evaluación de riesgo.
    -   **Probabilidad:** Media.
    -   **Mitigación:** Implementar patrones de resiliencia (circuit breaker, reintentos), utilizar el mock server como fallback en entornos controlados, considerar caching de tarifas si la frecuencia de actualización lo permite.
2.  **Nombre:** Complejidad del Mapeo de Datos.
    -   **Descripción:** El formato de las `tarifas_cat` proporcionado por `Plataforma-core-ohs` podría ser complejo o variar, dificultando el mapeo preciso al formato interno del sistema.
    -   **Impacto:** Errores en la interpretación de tarifas, cálculos incorrectos, mayor esfuerzo de desarrollo y mantenimiento del adaptador.
    -   **Probabilidad:** Baja a Media (dependiendo de la documentación y estabilidad del contrato de API).
    -   **Mitigación:** Realizar un análisis exhaustivo del contrato de API, definir claramente el esquema de datos interno, implementar pruebas unitarias y de integración robustas para el adaptador.

## 17. Criticality
**Criticality Level:** Alta
**Justification:** La historia fue marcada con "Prioridad: Alta" por el usuario. Es fundamental para la función principal del motor de cálculo, ya que permite la aplicación de factores de riesgo esenciales para la precisión de las primas.
**Feature Impact:** Sin la implementación de esta historia, el sistema no podrá aplicar los factores de catástrofe, lo que resultaría en cálculos de primas incorrectos, una evaluación de riesgo incompleta y potenciales pérdidas financieras o regulatorias.
**Critical Dependencies:** El motor de cálculo de pólizas y cualquier funcionalidad que dependa de la evaluación de riesgo geográfico.
**Recommended Priority:** Sprint actual / Inmediata.

## 18. Identified Assumptions
1.  **Formato Estable de `tarifas_cat`**
    -   Description: Se asume que el servicio `Plataforma-core-ohs` proporcionará las `tarifas_cat` en un formato estructurado y consistente (ej. JSON) que contendrá explícitamente la `zona_riesgo` y el `factor_catastrofe`.
    -   Impact if false: Si el formato es inestable, inesperado o carece de información clave, el adaptador no podrá procesar las tarifas, llevando a fallos en el cálculo.
    -   Requires validation from: Equipo de `Plataforma-core-ohs` y/o definición formal del contrato de API.
2.  **Consistencia de `zona_riesgo`**
    -   Description: Se asume que la conceptualización y nomenclatura de las `zona_riesgo` en `Plataforma-core-ohs` es compatible o directamente mapeable con la utilizada por el motor de cálculo del sistema.
    -   Impact if false: Si las zonas no coinciden o no hay un mapeo claro, el sistema no podrá aplicar el factor correcto.
    -   Requires validation from: Equipo de negocio, expertos de dominio y equipo de `Plataforma-core-ohs`.
