## 6. Acceptance Criteria (3-5 criteria)
### AC-001: Consulta exitosa de tarifas de incendio
**Description:** Valida que el sistema puede consultar exitosamente las tarifas de incendio y recibir la información necesaria.

```gherkin
Scenario: El sistema consulta tarifas de incendio exitosamente
  Given que se requiere el cálculo de prima de incendio
  When el sistema consulta las tarifas de incendio al servicio `Plataforma-core-ohs`
  Then recibe la información de tasas y factores relevantes
```

### AC-002: Disponibilidad de datos para el módulo de cálculo
**Description:** Valida que, una vez recibidos, los datos de las tarifas están disponibles para su uso.

```gherkin
Scenario: Los datos de tarifas de incendio están disponibles para el cálculo
  Given que la consulta de tarifas de incendio es exitosa
  And los datos de tasas y factores se han recibido
  When el módulo de cálculo de primas requiere esta información
  Then los datos están disponibles y accesibles para el cálculo
```

### AC-003: Manejo de fallos en la consulta de tarifas
**Description:** Valida que el sistema aplica una estrategia de reintento y registra fallos si el servicio externo no responde.

```gherkin
Scenario: El servicio de tarifas de incendio no responde
  Given que el sistema consulta el servicio de tarifas de incendio
  When el servicio `Plataforma-core-ohs` no responde
  Then el sistema aplica la estrategia de reintento configurada
  And si el fallo persiste después de los reintentos, se registra el incidente en los logs
```

**BR-001:** Estrategia de reintento para la consulta de tarifas
- Description: Define cómo el sistema debe intentar nuevamente la consulta al servicio de tarifas si falla la primera vez.
- Trigger: Falla en la comunicación o respuesta del servicio `Plataforma-core-ohs`.
- Logic: Implementar un patrón de reintento (ej. exponencial backoff) con un número máximo de intentos y un tiempo de espera entre ellos.
- Implementation: Cliente API REST.
- Exception: Si se supera el número máximo de reintentos, se considera un fallo persistente y se registra un error crítico.
