## 3. User Story
Como usuario,
Quiero que el sistema calcule la prima para el equipo electrónico basado en la suma asegurada y los factores correspondientes,
Para obtener un valor preciso para esta cobertura específica.

## 4. Functional Description
**Description:** El sistema debe calcular la prima correspondiente a la cobertura de equipo electrónico. Este cálculo se realizará utilizando la suma asegurada para el equipo electrónico y el factor de prima aplicable. El factor de prima puede variar según la clase o el nivel de zona de la ubicación asegurada. Si la suma asegurada para el equipo electrónico es cero, la prima resultante también debe ser cero.
**Flow:** HU-046 (Obtención de Factores) → HU-059 (Cálculo Prima Equipo Electrónico) → HU-054 (Cálculo Prima Neta)

## 6. Acceptance Criteria (3-5 criteria)
### AC-001: Cálculo Básico de Prima de Equipo Electrónico
**Description:** Valida que la prima de equipo electrónico se calcula correctamente utilizando la fórmula directa de suma asegurada por factor.

```gherkin
Scenario: Cálculo de prima con valores válidos
  Given la suma asegurada de equipo electrónico es 100000 y el factor de equipo electrónico aplicable es 0.005
  When se invoca el cálculo de prima de equipo electrónico
  Then el resultado de la prima de equipo electrónico es 500
```

### AC-002: Aplicación de Factor Variable por Ubicación/Clase
**Description:** Valida que el sistema selecciona y utiliza el factor de equipo electrónico correcto según la clase o el nivel de zona especificado.

```gherkin
Scenario: Selección de factor según clase o nivel de zona
  Given la suma asegurada de equipo electrónico es 50000 y la cobertura aplica a la 'Zona A' de 'Clase Industrial'
  When se invoca el cálculo de prima de equipo electrónico
  Then el sistema utiliza el factor de equipo electrónico correspondiente a la 'Zona A' de 'Clase Industrial' para el cálculo
```

### AC-003: Prima Cero para Suma Asegurada Cero
**Description:** Valida que la prima de equipo electrónico es cero si la suma asegurada para dicha cobertura es cero.

```gherkin
Scenario: Cálculo de prima con suma asegurada cero
  Given la suma asegurada de equipo electrónico es 0
  When se invoca el cálculo de prima
  Then el resultado de la prima de equipo electrónico es 0
```

## 16. Technical Notes and Risks
**Risks:**
1.  **Precisión y Actualización de Factores:**
    -   Description: La exactitud y la actualización de los factores de equipo electrónico obtenidos de HU-046 son críticas. Un factor erróneo o desactualizado resultaría en un cálculo de prima incorrecto.
    -   Impact: Pérdidas financieras para la compañía, insatisfacción del cliente, problemas de cumplimiento regulatorio.
    -   Probability: Media
    -   Mitigation: Establecer un proceso robusto de gestión y validación de factores en HU-046, implementar validaciones en el punto de uso, y auditorías periódicas.
**Technical Debt:** [To be filled by operating team per scope and MVP]

## 17. Criticality
**Criticality Level:** Medium
**Justification:** Esta historia es un componente fundamental para la oferta de la cobertura de equipo electrónico y contribuye directamente al cálculo de la prima total de una póliza. Un cálculo incorrecto tiene un impacto directo en el negocio.
**Feature Impact:** La no implementación o el fallo de esta historia impediría el cálculo correcto de la prima neta (HU-054) y, por ende, la emisión de pólizas con cobertura de equipo electrónico.
**Critical Dependencies:** HU-046 (para la provisión de factores).
**Recommended Priority:** Sprint actual o próximo, dada su dependencia crítica para la funcionalidad de prima neta.

## 18. Identified Assumptions

    -   Description: Se asume que el sistema o módulo asociado a HU-046 siempre proporcionará los factores de equipo electrónico correctos y actualizados para todas las combinaciones válidas de clase y zona.
