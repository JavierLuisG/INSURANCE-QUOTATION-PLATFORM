## 2. Enabled Capability
**CAP-007:** Cálculo de Primas por Ubicación
**Business Value:** Permite el cálculo preciso de las primas por ubicación, reduciendo el riesgo de errores en la cotización y mejorando la competitividad.
**Requires:** HU-076 (Mapeo de Zona CAT en la Ubicación desde Código Postal - relacionado con HU-068)
**Enables:** HU-055 (Aplicar Factores CAT y FHM - Cálculo Final de Prima Técnica)
**Orchestrates:** Plataforma-core-ohs (o su mock)

## 3. User Story
Como sistema,
Quiero consultar las tarifas CAT (Catástrofes) desde el servicio `Plataforma-core-ohs` (o su mock),
Para poder realizar el cálculo preciso de las primas por ubicación según la zona CAT.

## 4. Functional Description
**Description:** Esta historia describe la funcionalidad del sistema para interactuar con el servicio `Plataforma-core-ohs` (o un mock) con el fin de obtener el factor CAT correspondiente a una zona de catástrofe específica. El sistema utilizará la zona CAT de una ubicación como parámetro de entrada para la consulta, y el factor CAT resultante será utilizado en el proceso de cálculo de primas. Se contempla el manejo de casos donde el factor CAT devuelto sea nulo o inválido, utilizando un valor por defecto o registrando una alerta.
**Flow:** [HU-068: Obtener Zona CAT de Ubicación] → [HU-081: Consultar Tarifas CAT] → [HU-076: Calcular Prima Final]

## 7. Data and Business Rules


| field | type | required | default | validation | catalog | example |

**BR-001:** Manejo de Factor CAT Nulo/Inválido
- Description: Cuando el factor CAT devuelto por el servicio `Plataforma-core-ohs` es nulo, no numérico o menor o igual a cero, el sistema debe aplicar un valor por defecto y registrar el incidente.
- Trigger: Recepción de un factor CAT inválido o nulo desde el servicio `Plataforma-core-ohs`.
- Logic:
  ```
  IF factorCAT_recibido IS NULL OR factorCAT_recibido IS NOT NUMERIC OR factorCAT_recibido <= 0 THEN
      factorCAT_a_usar = VALOR_POR_DEFECTO_CAT (ej. 1.0)
      REGISTRAR_ALERTA("Factor CAT inválido o nulo recibido para [zonaCAT]. Usando valor por defecto.")
  ELSE
      factorCAT_a_usar = factorCAT_recibido
  END IF
  ```
- Implementation: Módulo de consulta de tarifas.
- Exception: N/A

## 16. Technical Notes and Risks
**Risks:**
1.  **Disponibilidad de `Plataforma-core-ohs`**:
    -   Descripción: Si el servicio `Plataforma-core-ohs` no está disponible o tiene alta latencia, afectará el cálculo de primas.
    -   Impacto: Cálculos de prima incorrectos o demorados, afectando la experiencia del usuario y las ventas.
    -   Probabilidad: Media.
    -   Mitigación: Implementación de Circuit Breaker, reintentos con backoff, caché de tarifas CAT, valor por defecto.
2.  **Contrato de API de `Plataforma-core-ohs`**:
    -   Descripción: Cambios en la API de `Plataforma-core-ohs` sin previo aviso podrían romper la integración.
    -   Impacto: Fallos en la consulta de tarifas, errores en el cálculo.
    -   Probabilidad: Baja (si hay buena comunicación entre equipos).
    -   Mitigación: Monitoreo de la integración, pruebas de integración automatizadas, comunicación con el equipo de `Plataforma-core-ohs`.

**Technical Debt:** [To be filled by operating team per scope and MVP]
- Considerar la implementación de un caché distribuido para las tarifas CAT para reducir la dependencia de llamadas repetidas al servicio externo.

## 17. Criticality
**Criticality Level:** Alta
**Justification:** La precisión en el cálculo de primas es fundamental para el negocio. Sin la consulta de tarifas CAT, los cálculos serían incorrectos o incompletos, lo que podría llevar a pérdidas financieras o a cotizaciones no competitivas.
**Feature Impact:** La no implementación o falla de esta historia detendría o invalidaría el cálculo de primas por ubicación, impactando directamente la funcionalidad central de cotización de seguros.
**Critical Dependencies:** HU-076 (Cálculo de Prima Final) depende directamente de esta historia para obtener el factor CAT.
**Recommended Priority:** Sprint actual / Próximo sprint
